What it tests

Why it’s hard for a language model

Models write good code when they have seen a thousand similar programs. DemoBench takes that away, then asks for something that has to look and sound good.

01

A computer nobody has programmed

DB32 was designed for this benchmark. There are no tutorials, forum answers or open-source demos to remember. The agent learns the instruction set from a short manual and by experiment.

02

4,096 bytes for everything

Code, 3D scenes, animation and a soundtrack share one cartridge, about a thousand instructions. There is no room to store pictures or samples, so everything is generated by code.

03

Nothing comes built in

No fonts, sprites, samples, synthesiser or 3D engine. Ray tracers, drum machines, reverbs and camera paths are all written from scratch in assembly.

04

Real hardware limits

An integer CPU, a 64-lane GPU with its own instruction set, and 128 KiB of RAM that two framebuffers nearly fill. Work has a per-frame budget, and a wrong memory access stops the machine.

05

It has to look and listen

The output is pictures and sound, not a value a test can compare. Agents render frames, inspect the images and check the audio, then fix what they find, over many rounds.

06

No answer key

“Make a demo” has no correct output. What it shows, how it moves and how it sounds is up to the agent, and that is what people judge.

Try it

Give your agent the kit

One repository with everything an agent needs to write a demo. It runs offline with Node.js 22 and needs no Rust toolchain.

  • The authoring skill and the machine manual
  • The pinned reference engine and a compressor
  • A validator that captures frames, audio and a report
  • A local viewer with an editor and WebGPU preview
Get the agent kit Engine source

  1. Clone the kit

    Or install it as the demo-bench folder in your agent’s skills directory.

    git clone https://github.com/janekm/demobench-agent-kit.git

  2. Ask your agent for a demo

    It reads SKILL.md, writes assembly, and checks its own frames and audio.

    Follow SKILL.md in demobench-agent-kit and make a 30-second demo with music.

  3. Validate and watch

    The validator runs the cartridge headlessly on the reference engine. The viewer plays it at 127.0.0.1:4173.

    npm run validate -- ./demo.asm --frames 3600 --out ./artifacts/demo npm run viewer
